# TikLive AI Commerce Studio

แอป Windows สำหรับให้ **ตัวละคร AI (Virtual Host)** ดำเนินรายการขายสินค้าใน TikTok LIVE แทนการออกกล้องเอง
ตัวละครพูดด้วยเสียง AI ขยับปากตามเสียง ขยับศีรษะ/ตา/ใบหน้า แสดงอารมณ์และท่าทาง เปลี่ยน Scene แสดงสินค้า ราคา
โปรโมชั่น ตอบคำถาม และสรุปผล LIVE โดย **แจ้งผู้ชมชัดเจนเสมอว่าเป็นตัวละคร AI**

> ภาพและเสียงออกอากาศผ่าน OBS (Browser Source) หรือหน้าต่าง Stage → TikTok LIVE Studio / stream key ทางการเท่านั้น
> แอปไม่ควบคุม TikTok เอง ไม่ดึงคอมเมนต์ ไม่ scrape และไม่มีฟีเจอร์ปั๊มยอดใด ๆ

## ความสามารถ

| ความสามารถ | ทำอย่างไร |
|---|---|
| พูดแนะนำสินค้า / อธิบายสินค้า | `HostBrain.pitch` สร้างจากข้อมูลสินค้าที่ผู้ขายกรอก (หรือ LLM ที่ถูกจำกัดให้ใช้ข้อมูลนั้น) |
| ตอบคำถาม | ผู้ควบคุมวางคำถามจากแชต → AI ตอบจากข้อมูลสินค้าเท่านั้น ไม่รู้ให้ส่งต่อทีมงาน (โหมดอัตโนมัติ หรือให้คนอนุมัติก่อน) |
| เปลี่ยนสินค้า / อ่านโปรโมชั่น / พูดตาม Script | สคริปต์แบบขั้นตอน: พูด, แสดงสินค้า, AI แนะนำ, อ่านโปร, เปลี่ยน Scene, พัก, ช่วงตอบคำถาม |
| สนทนาต่อเนื่อง | จบสคริปต์แล้ววน / รอ / คุยต่อเรื่องสินค้าปัจจุบัน |
| เสียง AI | เสียง Windows ในเครื่อง (ฟรี ออฟไลน์) หรือ OpenAI-compatible TTS |
| ขยับปากตรงกับเสียง | แปลงข้อความไทย/อังกฤษเป็น viseme timeline + วัด amplitude ของเสียงจริง |
| ขยับศีรษะ/ตา/ใบหน้า, อารมณ์, gesture, จังหวะหยุด | `AvatarController`: กะพริบตา, saccade, หายใจ, ศีรษะ drift, ผสมอารมณ์ 7 แบบ, ท่าทาง 8 แบบ, หยุดตามเครื่องหมายวรรคตอน |
| Scene / สินค้า / ราคา / โปรโมชั่น | Stage 1080×1920 พร้อมการ์ดสินค้า แบนเนอร์โปร คำบรรยาย และฟองคำถาม |
| สรุปผล LIVE | จาก event log ของแอป + ยอดที่ผู้ขายกรอกจาก TikTok LIVE Studio / Seller Center |

## การเปิดเผยว่าเป็น AI (บังคับ ปิดไม่ได้)

- ป้าย **"AI Virtual Host · ผู้ดำเนินรายการเป็นตัวละคร AI"** อยู่บนจอตลอด และมีป้าย AI บนชุดตัวละคร
- ประโยคแรกของทุกไลฟ์คือการแนะนำตัวว่าเป็นตัวละคร AI และแจ้งซ้ำทุก 15 นาที
- ผู้ชมถามว่า "เป็นคนจริงไหม" → ตอบตามจริงเสมอ
- ข้อความใดที่อ้างว่าเป็นคนจริงจะไม่ถูกพูด (ทั้งจาก LLM, สคริปต์ และที่ผู้ควบคุมพิมพ์)

## กฎเนื้อหาก่อนพูดทุกประโยค (`packages/compliance`)

บล็อก: การันตีผล, อ้างรักษาโรค, ลดน้ำหนัก/ผิวขาวเป็นตัวเลข, "ไม่มีผลข้างเคียง", อ้างแพทย์รับรอง, ราคาไม่ตรงข้อมูล,
อ้างของเหลือน้อยเกินจริง, อ้างส่วนลดโดยไม่มีราคาเดิม, อ้างจำนวนผู้ชม/ยอดสั่ง, บอกว่ามีของทั้งที่หมด
เตือน: อ้างอันดับ 1 ที่ต้องมีหลักฐาน, เร่งเร้าการซื้อเกินควร
ก่อนเริ่มไลฟ์ต้องผ่าน preflight (ตัวละคร, ป้าย AI, ราคา, ข้อความสินค้า/โปร/สคริปต์) ไม่ผ่านเริ่มไม่ได้

## สิ่งที่ระบบนี้ไม่ทำ (ถูกล็อกในโค้ด)

`packages/compliance/src/policy.ts` มีรายการความสามารถต้องห้าม ถ้า integration ใดประกาศใช้จะ throw ตั้งแต่เริ่มระบบ:
ปั๊มผู้ชม/ไลก์/คอมเมนต์/ผู้ติดตาม, spam, fake engagement, bypass CAPTCHA/แบน/การบังคับใช้กฎ, ปลอม device fingerprint,
account farming, ขโมย cookie, เก็บรหัสผ่าน, scraping TikTok, reverse engineer private API, browser automation เพื่อหลบข้อจำกัด,
สร้างพฤติกรรมปลอม ฟังก์ชันที่ TikTok ไม่มี API ทางการจะแสดง
"ฟังก์ชันนี้ต้องดำเนินการผ่าน TikTok LIVE Studio หรือเครื่องมือที่ TikTok รองรับ"

## โครงสร้าง

```
apps/
  desktop/   Electron (Windows) – เปิด API ในเครื่อง + หน้าต่างควบคุม + หน้าต่าง Stage
  studio/    React + Vite – ห้องควบคุม, สินค้า/โปร, ตัวละคร, สคริปต์, สรุปผล, Stage (#/stage)
  api/       Fastify + WebSocket – LiveDirector, REST, JSON store
packages/
  shared/      types, zod schemas, ตัดประโยคภาษาไทย
  compliance/  ป้าย AI, ตรวจคำโฆษณา, preflight, รายการความสามารถต้องห้าม
  ai/          LLM provider (OpenAI-compatible), HostBrain, annotate (อารมณ์/ท่าทาง/จังหวะ), สรุปผล
  tts/         TTS providers, viseme lip sync (ไทย+อังกฤษ), amplitude lip sync
  avatar/      AvatarController (ตา ศีรษะ อารมณ์ ท่าทาง ปาก)
  tiktok/      TikTokProvider: Manual (ค่าเริ่มต้น) / Official API (เมื่อได้รับอนุมัติ)
```

## เริ่มใช้งาน (พัฒนา)

```bash
pnpm install
pnpm build          # build ทุกแพ็กเกจ + UI + bundle Electron
pnpm test           # unit + API tests
pnpm desktop        # เปิดแอป Electron
pnpm package:win    # สร้างตัวติดตั้ง Windows (.exe) ใน apps/desktop/release (รันบน Windows)
```

หรือรันแบบเบราว์เซอร์: `pnpm --filter @tlai/api start` แล้วเปิด http://127.0.0.1:4417

ตั้งค่า LLM/TTS: คัดลอก `.env.example` ไปไว้ที่โฟลเดอร์ข้อมูลของแอป (เมนู Studio → เปิดโฟลเดอร์ข้อมูล) ชื่อ `.env`
ไม่ตั้งค่าก็ใช้ได้: สมองแบบ template ออฟไลน์ + เสียง Windows (ติดตั้งเสียงไทยได้ที่ Settings → Time & language → Speech)

## ออกอากาศ

1. เปิดแอป → หน้าต่าง Stage จะเปิดอัตโนมัติ (หรือ OBS → Browser Source → `http://127.0.0.1:4417/#/stage`, 1080×1920, เปิด "Control audio via OBS")
2. ใน OBS ส่งออกไปยัง TikTok LIVE Studio (Virtual Camera) หรือ stream key ที่ TikTok ให้บัญชีคุณ
3. ห้องควบคุม: สร้างไลฟ์ → ตรวจสอบ → เริ่ม LIVE
4. คัดลอกคำถามจากแชต TikTok มาวาง AI จะตอบ (หรือให้คนอนุมัติก่อน)
5. ปักสินค้าในตะกร้าทำใน TikTok LIVE Studio / Seller Center
6. จบ LIVE → กรอกยอดจาก TikTok → ดูสรุปผล
