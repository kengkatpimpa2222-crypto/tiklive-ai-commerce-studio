# คู่มือเริ่มไลฟ์จริงด้วย TikLive AI Commerce Studio

## 0. สิ่งที่ต้องมีก่อน

- คอมพิวเตอร์ Windows 10 หรือ 11 (64-bit)
- บัญชี TikTok ที่**มีสิทธิ์ LIVE และใช้ TikTok LIVE Studio ได้** เกณฑ์เป็นของ TikTok เอง (เช่น อายุ จำนวนผู้ติดตาม สถานะบัญชี) แอปนี้ช่วยเรื่องนี้ไม่ได้
  วิธีเช็กง่ายที่สุด: เปิด TikTok LIVE Studio แล้วล็อกอิน ถ้ากดปุ่ม Go LIVE ได้ แปลว่าใช้ได้
- ถ้าจะขายของในไลฟ์ (มีตะกร้าสินค้า) บัญชีต้องเป็นร้านค้า TikTok Shop หรือครีเอเตอร์ Affiliate ที่เปิดการขายผ่าน LIVE แล้ว
- มีคนดูแลหน้าจอระหว่างไลฟ์ (คัดลอกคำถามจากแชต ปักสินค้า และหยุดไลฟ์ได้ทันที) TikTok ไม่สนับสนุนไลฟ์ที่ปล่อยไว้โดยไม่มีใครดูแลหรือดูเหมือนวิดีโออัดไว้

## 1. ติดตั้งเสียงภาษาไทยใน Windows (ครั้งเดียว)

Settings → Time & language → Speech → Manage voices / Add voices → เลือก **ภาษาไทย (Thai)** → Add
ถ้าไม่ติดตั้ง ตัวละครจะขยับปากแต่ไม่มีเสียง (ในแอปจะขึ้นคำเตือนสีส้ม)

## 2. ติดตั้งแอป

- **แบบติดตั้ง:** ดับเบิลคลิก `TikLive-AI-Commerce-Studio-Setup-0.4.0.exe`
  (ดาวน์โหลดเวอร์ชันล่าสุดได้ที่ https://github.com/kengkatpimpa2222-crypto/tiklive-ai-commerce-studio/releases/latest)
- **อัปเดตอัตโนมัติ:** ตั้งแต่ 0.4.0 เป็นต้นไป ไม่ต้องดาวน์โหลดเองอีก แอปเช็กเวอร์ชันใหม่ตอนเปิดและทุก 1 ชั่วโมง
  ดาวน์โหลดเบื้องหลัง แล้วถามว่าจะรีสตาร์ทเพื่ออัปเดตเลยหรือไม่ ถ้ากำลังไลฟ์อยู่จะไม่ถาม แต่จะติดตั้งให้ตอนปิดโปรแกรม
  ข้อมูลสินค้า ตัวละคร และสคริปต์อยู่ครบหลังอัปเดต เช็กเองได้ที่เมนู Studio → ตรวจหาอัปเดต

ไฟล์ยังไม่ได้เซ็นรับรอง Windows อาจขึ้น "Windows protected your PC" ให้กด **More info → Run anyway**

## 3. เตรียมในแอป

เปิดแอปแล้วจะมี 2 หน้าต่าง: **ห้องควบคุม** และ **Stage (AI Virtual Host)** (ภาพที่จะออกไลฟ์)

1. **ตัวละคร AI:** ด้านบนมี "เลือกตัวละครสำเร็จรูป" (ผู้หญิง 2 ผู้ชาย 2) กด **ใช้ตัวนี้** แล้วตัวนั้นจะเป็นพิธีกรหลัก (★) ที่ขึ้นไลฟ์อัตโนมัติ จากนั้นตั้งชื่อ เลือกเสียง กด "ทดลองเสียง"
   - **หน้าตาเหมือนคนจริง:** หัวข้อ "หน้าตา" เลือก **เหมือนคนจริง (จากรูปถ่าย)** แล้วกด "เลือกรูปใบหน้า"
     ใช้รูปหน้าตรง มองกล้อง ปากปิด เห็นหน้าชัด ไม่ใส่แว่นกันแดด แนวตั้งครึ่งตัว ความละเอียดอย่างน้อย 1080 px
     แอปหาใบหน้าในเครื่องคุณเอง (ไม่ส่งรูปไปที่ไหน) แล้วกด "ทดลองให้พูด" ดูได้ทันที
     ต้องติ๊กยืนยันว่าเป็นเจ้าของรูปหรือบุคคลในรูปยินยอม จึงจะบันทึกได้ ห้ามใช้รูปคนดังหรือคนที่ไม่ได้อนุญาต
     ตัวละครจะขยับปากตามเสียง กะพริบตา ยิ้ม และขยับหัวเล็กน้อย ป้าย AI Virtual Host ยังอยู่บนจอตลอด
     รูปพื้นหลังของรูปถ่ายจะเป็นฉากหลังของไลฟ์ (ท่าทางมือมีเฉพาะแบบการ์ตูน)
2. **สินค้าและโปรโมชั่น:** ลบสินค้าตัวอย่าง แล้วใส่สินค้าจริง รูปสินค้า ราคา สต็อก จุดเด่นที่เป็นความจริง และข้อมูลจำเพาะ (AI จะพูดจากข้อมูลตรงนี้เท่านั้น) ใส่วันหมดเขตโปรได้ จอจะนับถอยหลังให้
3. **ร้านและหน้าจอ:** ใส่ชื่อร้าน ภาพพื้นหลัง ปรับขนาดและตำแหน่งตัวละคร และแก้ "ข้อมูลร้าน" (การจัดส่ง การชำระเงิน การคืนสินค้า) ให้ตรงกับนโยบายจริงของร้าน
4. **สคริปต์:** กด "✨ สร้างสคริปต์อัตโนมัติ" เลือกสินค้า ใส่ความยาวไลฟ์ แล้วกดสร้าง
5. **ห้องควบคุม:** สร้างไลฟ์ (เลือกตัวละคร สคริปต์ และสินค้า) แล้วกด **ตรวจสอบ** ให้ "ความพร้อมก่อนไลฟ์" เป็นสีเขียวทุกข้อ

### ตัวละครถือสินค้า (แบบไลฟ์ AI ทั่วไป)

ใช้รูปคนถือสินค้าไว้ข้างแก้มหรือระดับอก แอปหามือในรูปให้เอง มือและสินค้าจะนิ่ง ไม่บิดตามหน้า และยกขึ้นเล็กน้อยตอนแนะนำสินค้า
อย่าให้มือหรือสินค้าบังปาก ระหว่างพูดจะมีป้าย "AI กำลังพูดขาย" ขึ้นบนจอ และภาพจะซูมเข้า-ออกช้า ๆ เหมือนกล้องถ่ายสด

### เสียงผู้หญิงวัยรุ่น (เสียง AI ของ Microsoft)
Windows มีเสียงภาษาไทยในเครื่องแค่เสียงผู้ชาย (Pattara) ถ้าต้องการเสียงผู้หญิง ใช้เสียง AI ของ Microsoft ผ่าน Azure Speech แพ็กเกจ Free F0 ใช้ฟรีเดือนละประมาณ 5 แสนตัวอักษร
1. สมัคร Azure ที่ portal.azure.com แล้วสร้าง "Speech service" เลือก Free F0 และ region Southeast Asia
2. เปิด "Keys and Endpoint" คัดลอก KEY 1 และ Region
3. หน้า "ตัวละคร AI" ที่หัวข้อเสียง เลือก "เสียง AI ของ Microsoft" วาง key แล้วกด "บันทึก key"
4. กดแบบเสียง "สาววัยรุ่น สดใส" แล้วกด "ทดลองเสียง" และ "บันทึก"
ถ้าเน็ตหลุดหรือโควตาหมด ตัวละครจะใช้เสียงในเครื่องแทนชั่วคราว

### ตัวละครหน้าเหมือนคนจริง (บริการอวตาร AI ของ D-ID)

ตัวการ์ตูนและตัวจากรูปถ่ายฟรี แต่ถ้าอยากได้คนจริงขยับปากตรงเสียงแบบในโฆษณาไลฟ์ AI ให้ใช้บริการ D-ID (เสียค่าบริการกับ D-ID เอง แอปนี้ไม่เก็บเงิน)

1. สมัครที่ studio.d-id.com แล้วเลือกแพ็กเกจ **API** ที่มี Streaming (ดูราคาล่าสุดที่หน้า Pricing → API)
2. มุมขวาบน → **API Key** → Generate แล้วคัดลอก key
3. ในแอป ไปที่ **ตัวละคร AI** → การ์ด "ตัวละครคนจริง" วาง key แล้วกด **บันทึก** (แอปจะตรวจว่า key ใช้ได้ก่อนบันทึก)
4. เลือกคนที่ชอบ กด **ใช้ตัวนี้** ตัวนั้นจะเป็นพิธีกรหลัก ★ พูดไทยด้วยเสียง Microsoft (เปรมวดี อัจฉรา หรือนิวัฒน์ เปลี่ยนได้ในหน้าแก้ตัวละคร)
5. เปิดหน้าจอ Stage แล้วเริ่มไลฟ์ตามปกติ หน้าจอ Stage จะเชื่อมวิดีโอกับ D-ID เอง (ภาพตัวอย่างในห้องควบคุมเป็นภาพนิ่งเพื่อไม่ให้เสียเครดิตซ้ำ)

- ทุกคำที่อวตารพูดมาจากแอปนี้และผ่านการตรวจกฎเดิม ป้าย AI Virtual Host ยังอยู่บนจอตลอด
- คิดเงินตามนาทีที่อวตารพูด ไลฟ์ยาว ๆ ใช้นาทีเยอะ ดูเครดิตคงเหลือได้ที่การ์ดเดียวกัน
- ถ้าเชื่อม D-ID ไม่ได้ระหว่างไลฟ์ ห้องควบคุมจะขึ้นข้อความสีส้ม และประโยคนั้นจะพูดด้วยเสียงในเครื่องแทน ไลฟ์ไม่หยุด

### เพลงพื้นหลัง ข้อความวิ่ง และป้ายสต็อก (หน้า "ร้านและหน้าจอ")

- **เพลงพื้นหลัง:** เลือกไฟล์เพลงของคุณเอง (mp3, m4a ไม่เกิน 20 MB) ตอน AI พูดเพลงจะเบาลงเองแล้วกลับมาดังเมื่อพูดจบ ใช้เพลงที่มีสิทธิ์ใช้เท่านั้น
- **ข้อความวิ่ง:** แถบข้อความด้านล่างจอ เช่น เวลาตัดรอบส่งของ
- **ป้าย "เหลือ N ชิ้น":** แสดงบนการ์ดสินค้าเมื่อสต็อกเหลือน้อย ใช้ตัวเลขที่ใส่ในหน้าสินค้า ต้องอัปเดตให้ตรงกับร้านจริง

### เพิ่มสินค้าเร็ว ๆ จากลิงก์หรือข้อความ

เมนู **สินค้าและโปรโมชั่น** ช่อง "เพิ่มสินค้าจากลิงก์หรือข้อความ" วางอย่างใดอย่างหนึ่งแล้วกด **ประมวลผล**:
- ลิงก์หน้าสินค้าจากเว็บร้าน: อ่านชื่อ ราคา รูป รายละเอียด ที่เว็บเปิดให้ดูตัวอย่าง (ถ้าเว็บไม่อนุญาตหรือไม่มีข้อมูล จะบอกให้วางข้อความแทน)
- ลิงก์ TikTok: ระบบไม่เปิดอ่าน เพราะ TikTok ไม่อนุญาต ให้คัดลอกชื่อ ราคา รายละเอียดสินค้าจาก Seller Center มาวางแทน
- ข้อความที่คัดลอกมา: ใช้ได้กับทุกร้าน

ถ้าเปิดสมอง AI ไว้ AI จะเขียนจุดขายเป็นประโยคพร้อมพูดในไลฟ์ให้ ราคาต้องมีอยู่ในข้อมูลต้นทางเท่านั้น และจุดขายที่อาจผิดกฎโฆษณาจะถูกตัดออก ตรวจข้อมูล ใส่ SKU และสต็อก แล้วกดบันทึก

### คำถามที่ลูกค้าถามบ่อยของแต่ละสินค้า
1. หน้า "สินค้า" กด "แก้ไข" ที่สินค้า
2. ที่ "คำถามที่ลูกค้าถามบ่อย" กด "+ เพิ่มคำถาม" พิมพ์คำถาม เช่น "ผิวแพ้ง่ายใช้ได้ไหม" และคำตอบของร้าน
3. กด "บันทึก"
เมื่อมีคนถามคล้าย ๆ กัน (เช่น "ผิวแพ้ง่ายใช้ได้มั้ยคะ") ตัวละครจะตอบตามคำตอบของร้านก่อน คำตอบยังผ่านการตรวจกฎโฆษณาเหมือนข้อมูลอื่น ถ้าเขียนคำต้องห้าม เช่น "การันตี" หรือ "หายขาด" ระบบจะไม่ให้เริ่มไลฟ์จนกว่าจะแก้

### โค้ดส่วนลดบนจอ
ตอนเพิ่มโปรโมชั่น ใส่ "โค้ดส่วนลด" ให้ตรงกับที่ตั้งใน TikTok Shop โค้ดจะขึ้นบนแถบโปรตลอด และเมื่อตัวละครอ่านโปรนี้ โค้ดจะขึ้นตัวใหญ่กลางจอ 15 วินาที

### สินค้าที่ใช้คู่กัน
ในหน้าแก้ไขสินค้า ติ๊กสินค้าอื่นที่ใช้คู่กันได้ (สูงสุด 5 ชิ้น) ตัวละครจะแนะนำสินค้าคู่พร้อมราคาจริงตอนพูดถึงสินค้านี้ และตอบได้เมื่อลูกค้าถามว่า "ใช้คู่กับอะไรดี" สินค้าที่หมดหรือไม่ได้อยู่ในไลฟ์จะไม่ถูกแนะนำ

## 4. ต่อภาพและเสียงเข้า TikTok LIVE Studio

1. ดาวน์โหลด TikTok LIVE Studio (ในแอป: เมนู TikTok → เปิด TikTok LIVE Studio) แล้วล็อกอิน
2. เลือกเลย์เอาต์แนวตั้ง (Portrait)
3. เพิ่ม Source → **Window capture** → เลือกหน้าต่าง **Stage (AI Virtual Host)** แล้วลากให้เต็มกรอบ
4. เสียง: เปิดเสียงคอมพิวเตอร์ (Desktop/System audio) ใน LIVE Studio และปิดไมค์ถ้าไม่ใช้
   ห้ามเปิดหน้าต่าง Stage เกิน 1 หน้าต่าง ไม่อย่างนั้นเสียงจะซ้อนกัน
5. ตั้งชื่อไลฟ์ให้บอกว่าเป็นผู้ดำเนินรายการ AI เช่น "ไลฟ์ขายเซรั่ม | พิธีกร AI" และถ้า LIVE Studio มีตัวเลือกติดป้ายเนื้อหาที่สร้างด้วย AI ให้เปิดไว้

ถ้าใช้ OBS: Window Capture หน้าต่าง Stage + Application Audio Capture ของแอปนี้ แล้วส่งออกด้วย stream key ที่ TikTok ออกให้บัญชีคุณ หรือใช้ OBS Virtual Camera เข้า LIVE Studio

## 5. เริ่มไลฟ์

1. กด **Go LIVE ใน TikTok LIVE Studio** ก่อน
2. กลับมาที่ห้องควบคุม แล้วกด **เริ่ม LIVE** AI จะแนะนำตัวว่าเป็นตัวละคร AI จากนั้นเดินตามสคริปต์
3. ระหว่างไลฟ์:
   - ให้ AI ตอบคอมเมนต์ลูกค้า: ดูหัวข้อ 5.1 ข้างล่าง (คัดลอกคอมเมนต์ครั้งเดียว AI ตอบเอง)
   - ปักสินค้าในตะกร้าที่ LIVE Studio ให้ตรงกับสินค้าที่ AI กำลังพูด
   - ปุ่ม ⏸ หยุด / ▶ ต่อ / ⏭ ข้ามประโยค (คีย์ลัด F8 / F9) และช่อง "พิมพ์ให้ AI พูดทันที" ใช้ได้ตลอด
   - กล่องสีแดงด้านซ้ายบอกเวลาออกอากาศ เวลาที่จะแจ้งว่าเป็น AI ครั้งถัดไป และจำนวนคำถามที่รอตอบ

## 5.0 ตั้งเวลาไลฟ์อัตโนมัติ
1. หน้า "ห้องควบคุม" ที่กล่อง "ตั้งเวลาไลฟ์อัตโนมัติ" กด "+ เพิ่มเวลาไลฟ์"
2. เลือกวัน เวลาเริ่ม ความยาว และพิธีกร แล้วกด "บันทึกเวลา"
3. เปิดแอปทิ้งไว้ ก่อนถึงเวลา 10 นาทีแอปจะเตือน ให้เปิด TikTok LIVE Studio แล้วกด Go LIVE เอง
4. ถึงเวลาตัวละครจะเริ่มพูดเอง และพูดลาแล้วจบเองตามเวลาที่ตั้ง
แอปไม่กดเริ่มไลฟ์ใน TikTok แทนคุณ และต้องมีคนคอยดูแลไลฟ์ตลอด ถ้าเริ่มไม่ได้ (เช่น ไม่มีสินค้าเปิดขาย) แอปจะแจ้งเตือนและบอกเหตุผลไว้ในกล่องนี้

## 5.0.1 ราคาพิเศษจับเวลา (Flash sale)
1. ตั้งราคาพิเศษใน TikTok Shop ก่อน (เช่น Flash Deal หรือแก้ราคาสินค้า) ให้ลูกค้ากดซื้อได้ราคานั้นจริง
2. ระหว่างไลฟ์ ที่ห้องควบคุม กล่อง "ราคาพิเศษจับเวลา" เลือกสินค้า ใส่ราคาพิเศษ เลือกเวลา 5-30 นาที
3. ติ๊ก "ตั้งราคาใน TikTok Shop แล้ว" แล้วกด "เริ่มราคาพิเศษ"
หน้าจอจะขึ้นเวลานับถอยหลังและราคาพิเศษบนการ์ดสินค้า ตัวละครประกาศราคา เตือนตอนเหลือ 2 นาที และบอกเมื่อหมดเวลา หมดเวลาแล้วเปลี่ยนราคาใน TikTok Shop กลับเอง

## 5.0.2 ขอบคุณออเดอร์จริง
เมื่อเห็นออเดอร์ใหม่ใน TikTok Shop Seller Center ให้กด "🛒 มีคนสั่ง" ที่สินค้านั้นในห้องควบคุม จอจะขึ้นป้ายสั้น ๆ ตัวละครขอบคุณโดยไม่บอกชื่อลูกค้า และยอดสั่งซื้อในสรุปไลฟ์จะนับเพิ่มให้ กดเฉพาะออเดอร์จริงเท่านั้น ถ้ากดหลายครั้งติดกัน ตัวละครจะขอบคุณครั้งเดียว

## 5.1 ให้ AI ตอบลูกค้าอัตโนมัติ

**ทำไมยังต้องมีคนกดคัดลอก:** ตอนนี้ TikTok ไม่มี API ทางการที่ให้แอปภายนอกอ่านคอมเมนต์ LIVE ได้
เครื่องมือที่ "ดึงคอมเมนต์อัตโนมัติ" ที่เห็นทั่วไปใช้วิธีแกะระบบภายในของ TikTok ซึ่งผิดข้อกำหนด และเสี่ยงโดนแบนบัญชี
แอปนี้จึงไม่อ่านคอมเมนต์เอง แต่ทำให้ขั้นตอนของคนเหลือแค่ **คัดลอก 1 ครั้ง** ส่วนการตอบ AI ทำเองทั้งหมด

ตั้งค่าครั้งเดียว:
1. ห้องควบคุม → "คำถามจากผู้ชม" เลือก **AI ตอบอัตโนมัติ**
2. เปิดสวิตช์ **คัดลอกคอมเมนต์ = AI ตอบทันที** (หรือเมนู คำถามลูกค้า → ติ๊กอันเดียวกัน)

ระหว่างไลฟ์ เลือกวิธีใดวิธีหนึ่ง:
- **คัดลอกคอมเมนต์ (เร็วที่สุด):** ลากเลือกคอมเมนต์ใน TikTok LIVE Studio (หรือหน้า LIVE บนเว็บ/มือถือที่แชร์คลิปบอร์ด) แล้วกด `Ctrl+C`
  AI จะตอบบนจอทันที มีป๊อปอัป "ส่งให้ AI ตอบแล้ว" ยืนยัน ถ้าคัดลอกมาทั้งชื่อและข้อความ ระบบแยกชื่อลูกค้าให้เอง
- **Ctrl+Shift+A:** ส่งข้อความที่คัดลอกไว้ให้ AI ตอบ ใช้ได้แม้ปิดสวิตช์ เหมาะถ้าไม่อยากให้ทุกการคัดลอกกลายเป็นคำถาม
- **กล่องถามด่วน (Ctrl+Shift+Q):** หน้าต่างเล็กลอยเหนือ LIVE Studio พิมพ์สั้น ๆ เช่น "ส่งกี่วัน" แล้วกด Enter
  ใช้เมื่อคอมเมนต์ลากเลือกไม่ได้ กล่องนี้แสดงด้วยว่าคำถามไหน AI ตอบแล้วและตอบว่าอะไร

AI ตอบอย่างไร:
- ตอบได้ถึง 3 คำถามติดกันก่อนกลับไปพูดตามสคริปต์ คำถามที่ซ้ำ ลิงก์ หรือคำหยาบจะไม่ถูกตอบ
- ตอบจากข้อมูลสินค้า โปรโมชั่น และ "คำถามที่พบบ่อย" ในหน้าร้านเท่านั้น ถ้าไม่มีข้อมูลจะบอกว่าให้ทีมงานตอบในแชต
- ระหว่างช่วงพูดคุย AI จะหยิบคำถามที่พบบ่อย (ส่งกี่วัน, จ่ายปลายทาง, คืนสินค้า) มาตอบเองเป็นระยะ ก่อนลูกค้าจะถาม
  ยิ่งกรอกคำถามที่พบบ่อยในหน้า "ร้านและหน้าจอ" ไว้ครบ ลูกค้าก็ยิ่งต้องถามน้อยลง
- ถ้าคัดลอกในแอปนี้เอง (เช่นแก้ข้อมูลสินค้า) จะไม่ถูกส่งเป็นคำถาม

ถ้าวันหนึ่ง TikTok เปิด API คอมเมนต์ LIVE แบบทางการ แอปมีจุดเชื่อมต่อ (`OfficialTikTokProvider`) รอไว้แล้ว เปลี่ยนเป็นอัตโนมัติเต็มรูปแบบได้โดยไม่ต้องรื้อระบบ

### คำถามที่ AI ตอบไม่ได้
ถ้าไม่มีข้อมูลพอ ตัวละครจะบอกผู้ชมว่าทีมงานจะตอบ แล้วคำถามจะไปอยู่ในกล่อง "AI ตอบไม่ได้ รอทีมงานตอบ" ในห้องควบคุม พิมพ์คำตอบของร้าน (ข้อมูลจริงเท่านั้น) แล้วกด "ให้ตัวละครตอบ" ตัวละครจะพูดคำตอบในไลฟ์ และถ้าติ๊ก "จำคำตอบไว้" คำตอบจะถูกเก็บไว้ในคำถามที่ถามบ่อยของสินค้านั้น ครั้งหน้า AI ตอบเองได้ ถ้าตอบในแชตเองแล้ว กด "ตอบในแชตเองแล้ว" เพื่อเอาออกจากรายการ

## 5.2 ไม่ให้พูดวนซ้ำ

- AI มีประโยคหลายแบบสำหรับทุกเรื่อง (แนะนำสินค้า ราคา โปร ชวนถาม ทักทายตามช่วงเวลา สรุปสินค้า คำถามที่พบบ่อย)
  และจำสิ่งที่พูดไปแล้ว จะไม่พูดประโยคเดิมซ้ำในช่วงหลัง ๆ และสลับเรื่องที่พูดไม่ให้ติดกัน
- แนะนำสินค้าตัวเดิมรอบใหม่จะใช้คำพูดและลำดับจุดเด่นต่างจากรอบก่อน
- สคริปต์ที่ตั้งให้วนซ้ำ ประโยคที่เขียนตายตัวจะไม่ถูกพูดซ้ำภายใน 20 นาที
- จังหวะเว้นระหว่างประโยคไม่เท่ากันทุกครั้ง ฟังเป็นธรรมชาติขึ้น
- ยิ่งใส่จุดเด่น ข้อมูลจำเพาะ และคำถามที่พบบ่อยไว้มาก AI ก็ยิ่งมีเรื่องพูดหลากหลาย
  ถ้าใส่ LLM API key ใน .env AI จะเรียบเรียงคำพูดใหม่ได้เองอีกครึ่งหนึ่ง (ยังผ่านตัวตรวจกฎทุกประโยค)

## 5.3 ให้ตัวละครคิดคำพูดเอง (สมอง AI)

ค่าเริ่มต้น ตัวละครใช้ประโยคสำเร็จรูปที่สลับคำไม่ซ้ำ ถ้าอยากให้คิดคำพูดเองเป็นธรรมชาติเหมือนคนจริง ให้ต่อกับบริการ AI:

1. สมัครบัญชีกับผู้ให้บริการหนึ่งเจ้า แล้วสร้าง API key
   - Claude (Anthropic): https://console.anthropic.com/settings/keys (ภาษาไทยลื่นที่สุด)
   - ChatGPT (OpenAI): https://platform.openai.com/api-keys
   - Gemini (Google): https://aistudio.google.com/apikey (มีโควตาฟรีรายวัน)
2. เติมเครดิต/ผูกบัตรในเว็บผู้ให้บริการ และตั้งวงเงินสูงสุดต่อเดือนไว้ ค่าใช้จ่ายจ่ายให้ผู้ให้บริการตามที่ใช้จริง แอปนี้ไม่เก็บเงินเพิ่ม
3. ในแอปเปิดเมนู **สมอง AI** เลือกผู้ให้บริการ วาง key กด **ทดลองให้ AI คิดประโยค** แล้วกด **บันทึกและเปิดใช้**
4. ระหว่างไลฟ์ดูจำนวน token ที่ใช้ได้ในหน้าเดียวกัน เพื่อประเมินค่าใช้จ่ายต่อชั่วโมง

เมื่อเปิดแล้ว AI คิดเองทุกประโยค ทั้งแนะนำสินค้า พูดคั่น อ่านโปร และตอบลูกค้า จากข้อมูลที่ใส่ไว้เท่านั้น ทุกประโยคยังผ่านการตรวจ (ราคาต้องตรง ห้ามอ้างเกินจริง ห้ามบอกว่าเป็นคนจริง)
ถ้า AI ช้า ตอบผิดกฎ หรือเน็ตหลุด ตัวละครจะใช้ประโยคสำเร็จรูปแทนทันที API key เก็บอยู่ในเครื่องนี้เท่านั้น

## 7. สำรองข้อมูลและย้ายเครื่อง
หน้า "ร้านและหน้าจอ" กล่อง "สำรองข้อมูลและย้ายเครื่อง" กด "บันทึกไฟล์สำรอง" จะได้ไฟล์ .json หนึ่งไฟล์ ที่เครื่องใหม่ติดตั้งแอป แล้วกด "นำข้อมูลกลับจากไฟล์" ข้อมูลสินค้า ตัวละคร สคริปต์ โปรโมชั่น เวลาไลฟ์ ประวัติ รูป และเพลงจะกลับมาครบ API key ไม่ถูกบันทึกในไฟล์ ต้องใส่ใหม่ในเครื่องใหม่
